# ORBIS – Operation Weltatlas

Digitaler Escape Room für Erdkunde, Klasse 10: **Wachstum und Verteilung der Weltbevölkerung**.

▶ **Spielen:** https://herrwartenberg.github.io/weltbevoelkerung10/

- Eine einzige, selbstständige HTML-Datei (`index.html`), offline lauffähig
- 5 Kartenblätter + Kartenschrank, je Blatt 3 Schritte; Rätsel nur mit dem Schulbuchkapitel lösbar (nur Seitenverweise, keine Buchinhalte)
- Teams aus 3–4 Schüler:innen, Stoppuhr statt Countdown, 3 gestufte Hinweise pro Blatt, Fortsetzen über notierte Ziffern
- iPad-/Touch-tauglich (Ziehen oder ▲/▼-Buttons)

## Datenschutz
Keine externen Ressourcen, keine Cookies, kein Tracking, keine Speicherung im Browser. Content-Security-Policy sperrt Netzwerkzugriffe.
